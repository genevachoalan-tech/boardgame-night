# 🏰 冒险王之夜 · 桌游合集

五合一桌游联机网页游戏，支持多人实时对战。

## 🎮 游戏列表

1. **🐍 小蛇机** - 翻牌抽卡游戏，避开蛇头
2. **🍺 拍词酒杯** - 骰子策略游戏，控制酒杯液位
3. **⚔️ 酒馆争夺战** - 投骰占领酒馆，争夺金币
4. **🎯 冒险王之投了个骰** - 力度控制射击龙蛋
5. **🏰 逃生机制** - 地图移动+技能卡牌对战

## ✨ 功能特性

- 🎲 **开局猜大小**：每局开始前投骰比大小决定先手
- 👥 **多人联机**：支持2-6人分两队对战
- 🎩 **主持人模式**：主持人控制游戏流程
- 🔑 **断线重连**：支持重连码恢复游戏状态
- 📱 **响应式设计**：支持手机和电脑浏览器

## 📖 使用说明

### 主持人操作
1. 打开游戏页面，点击「🎩 我是主持人」创建房间
2. 将房间号分享给玩家
3. 所有玩家加入后，点击「开始游戏」
4. 每局开始前点击「投骰比大小」决定先手

### 玩家操作
1. 选择角色和队伍
2. 输入主持人分享的6位房间号
3. 点击「连接并加入」
4. 准备后等待主持人开始游戏

## 🛠️ 技术栈

- 纯 HTML + CSS + JavaScript
- PeerJS (WebRTC) 实现点对点联机
- 响应式设计，适配移动端
